# make-diagram

Prompt to one static HTML diagram: architecture, flowchart, sequence or state.
The agent writes a small JSON topology; scripts lay it out with ELK and render
it. Local, offline, and usable by any agent that can run shell commands.

Status: scaffold. The workflow, scripts and examples land in later tasks.
