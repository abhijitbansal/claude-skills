In short

A prompt becomes one file, openable anywhere

Good

Diagrams, dashboards, videos and explainers now share a theme, a checker and a rule: the model fills in JSON and a script renders it.

  • Each output is one local file with no network at build or view time.
  • Checks run before the render, so a bad spec fails with a path and a fix.
  • One set of themes keeps every artifact in the same family.

The skills

Each skill covers one kind of artifact

  • make-diagram

    Architecture, flow, sequence and state diagrams with zoom and hover tracing.

  • make-dashboard

    Charts and KPI pages built from local data files.

  • make-motion

    Short animated videos, previewed locally and exported to MP4.

  • make-explainer

    Recaps, checklists, concept pages and slide decks like this one.

Motion

Clips from make-motion play on their slide

The build

Every build follows the same four steps

  1. Write the outline

    Typed sections in one JSON file.

  2. Validate it

    Schema, file references and prose rules.

  3. Render it

    Themed HTML with fonts and script inlined.

  4. Open it

    One file: open it in a browser, or print it to PDF.

Why outlines

Outlines stay consistent; hand-written pages drift

Hand-written page

Caution
  • Spacing changes from page to page.
  • A font or script may come from a CDN.
  • Nothing checks the prose.

Generated from an outline

Good
  • One renderer per section type.
  • The content security policy blocks the network.
  • Banned phrases fail the build.

NoteKeys that work in the deck

Arrows, Space, Page Up and Page Down move between slides, and Home and End jump to the first and last. O opens the outline. A link such as #slide-3 opens that slide, and the last slide is remembered.

Long slides

A tall slide scrolls inside itself

What a tall slide does

A slide taller than the screen scrolls inside itself. Space scrolls it first and moves on at the bottom, and a table that scrolls sideways keeps the arrow keys while it has focus.

Embeds

Diagrams, charts and videos fit slides too

  • A diagram section draws a make-diagram figure with hover tracing and a Present mode.
  • A chart section draws a make-dashboard chart as a static image with a data table.
  • A motion section plays a clip, like the one on slide 4, and never autoplays.
