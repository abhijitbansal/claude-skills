Scope

Three goals, and what the PR leaves alone#

Goals:

  • No number, percentage or number-plus-unit token splits across two lines.
  • Render skills can run on a cheap model in Copilot and Codex, not only Claude Code.
  • A plan page a reviewer answers in place, with answers the agent can check.

Non-goals:

  • Reflowing ordinary prose or changing stored spec text.
  • Guaranteeing the hand-off: no host lets a skill force another agent.
  • A save server or any new npm dependency.

What could still go wrong
  • The hand-off agent fails. One Copilot trial was refused file access; the main agent finished the work itself.
