Cache Clock · GitHub Copilot CLI

One idle gap, one 25× price.

Copilot bills tokens in AI credits. When the prompt cache expires, the next message rewrites your whole conversation at the cache-write price. Cache Clock shows the clock, prices the send, and drops a costly cold send once so you can decide.

Tested on Copilot CLI 1.0.95 · numbers measured 11 October 2026 · 1 AI credit = $0.01

1 · The problem

A cache write costs far more than a cache read

On Claude and newer GPT models in Copilot, writing a prompt to cache is priced well above reading it back. The cache also expires. Step away longer than the TTL (time to live) and the next message, even “give me a recap”, pays the write price for everything.

The estimate (37.2k) is the last call’s input plus its answer. The real resend also carried your new message and what Copilot attaches, so it wrote 44,388.

2 · The clock

Copilot reports the expiry, so nothing is guessed

Every main-agent model call emits an assistant.usage event. It carries the cache numbers and the prices. Cache Clock keeps the last call for each model.

/cache-clock — the card, from a real resumed session 
cache-clock · Claude Sonnet 5.5
  cache      warm, 1m17s left (ttl 5m00s)
  context    37.2k tokens
  next send  warm $0.003 · cold $0.08 (25× per token)
  session    5 model calls · 0 cold after idle · 0 prefix breaks · $0 extra paid
  guard      refuse once above $0.10 · heads-up 5m before expiry

Prices come from the payload: nano-AI-credits per batch of tokens, and 1 credit is $0.01. Prices already include discounts. Through auto, Sonnet’s write was $2.25/M (list $2.50).

3 · The guard

A cold send is refused once, then your call

The hook onUserPromptSubmitted runs on every message you send. It asks four questions, in this order. Only one path stops the message.

The refusal — a real capture (Copilot CLI 1.0.95, 11 October 2026, taken with /cache-clock min 0.01) 
! cache-clock: the Claude Sonnet 5.5 prompt cache went cold 2s ago. Sending this rewrites
  about 37.2k tokens at $2.25/M = $0.08 (a warm send would read them for $0.003).
  Send it again to pay it, or /clear and start fresh.
The resend’s note — template, one line 
cache-clock: sending cold, rewriting about <tokens> tokens for <cold $> (warm: <warm $>).

Switch modes with /cache-clock guard refuse (default), warn (send and print the price) or off.

4 · The heads-up

A warning one minute before a Claude cache expires

One ephemeral line appears before expiry. It fires only when a cold send’s extra cost (cold minus warm) is at least the threshold and no turn is running. The lead time is the smaller of your setting (5 min) and a fifth of the TTL. A 5-minute lead on a 5-minute cache would fire right after every call.

Change it with /cache-clock headsup 5, or headsup off. It keeps running under guard off until you turn it off.

5 · Resume

A resumed session reads its clock from the log

assistant.usage is not replayed when you resume, and getEvents() omits usage records. So the extension reads the session’s own log, which keeps every record with its prices.

6 · The report

See what cold sends already cost you

The extension only sees sessions it was loaded in. The report reads every session Copilot has persisted, CLI and VS Code alike. It sends nothing anywhere. It needs Node 18+.

Run it 
node tools/cache-clock/bin/report.mjs              # last 30 days
node tools/cache-clock/bin/report.mjs --since 7d   # or 12h, all; --json for raw numbers
Sample output — the test machine after the README’s experiments

■ cold after idle

The call came after the reported expiry. The fix is behavior: send sooner, or accept the price.

▲ prefix break

A cold call inside the TTL. Something changed the prompt prefix (tools, instructions, model routing), or the provider served it cold early.

“Extra paid” is what each cold call cost above a warm read of the same tokens. Some VS Code sessions persist only totals, not per-call records; the report counts them separately.

Limits

▲ early eviction

The guard trusts cacheExpiresAt. When a provider serves the cache cold sooner (Luna at 29 of 30 min, once), the send is billed cold and the guard stays quiet. The report counts it as a prefix break.

▲ approximate price

The estimate is the last call’s input plus its answer. The real resend adds your message and attachments (44.4k actual vs 37.2k estimated). Copilot’s shared system prefix (~10k tokens) often stays cached, which pulls the other way.

▲ no keep-warm yet

cache-tax pings to hold the cache. An extension can only ping with session.send, which adds a user and an assistant turn each time. Run the report to see if pings would pay off.

◆ other limits

With auto, the next prompt may route to another model; the guard prices the last model used. In -p mode, /cache-clock needs the interactive CLI. Claude was measured through auto only; each boundary result is a single run.
