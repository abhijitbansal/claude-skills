Connections

  • Customer → Mobile app: taps place order
  • Mobile app → API gateway: posts order
  • API gateway → Orders service: routes order
  • Orders service → Payments service: requests charge
  • Payments service → Card provider: charges card
  • Card provider → Payments service: returns approval
  • Payments service → Orders service: confirms payment
  • Orders service → Orders database: writes order
  • Orders service → Event queue: publishes order event
  • Restaurant tablet → Orders service: accepts order
  • Event queue → Courier app: offers the job
  • Courier app → Customer: drops off order
