# make-motion 2: Cut-over Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** make-motion contains one generation. The version 1 engine, its scripts, tests, examples, references and npm dependencies are gone; everything that names them (the skill's own docs, make-explainer, the eval harness, the plugin's guard tests, CI, the plugin and repo docs) describes version 2; every suite is green after each task.

**Architecture:** Four moves in a fixed order. (1) Untangle: the few version 1 modules version 2 imports are moved or cut free, and a guard test proves no kept file reaches into the tree that will be deleted. (2) Switch: every consumer of a version 1 entry point (SKILL.md and its guard tests, make-explainer, the eval harness) is pointed at `scripts/make.mjs` while version 1 still exists. (3) Delete, in one commit, with the guard tests and CI job that name deleted files. (4) Trim dependencies, then rewrite the documents.

**Tech Stack:** The version 2 engine as it stands. `node:test`, bats, pytest. No new npm dependency; lockfiles only lose packages.

**Spec:** `docs/superpowers/specs/2026-11-15-portable-artifacts-2-design.md`: section 8.7 (carry-overs), 8.8 (what a version 1 spec gets), 10 (director and operator, only as a boundary), 11 (dependencies and security), 12 (authoring support), 15 step 6 (this plan) and steps 7 to 10 (not this plan). Measured records: `docs/superpowers/plans/2026-11-15-pa2-gate-report.md`. Open owner calls: `docs/decisions-pending.md`.

Abbreviations: `P` = `plugins/portable-artifacts`, `M` = `P/skills/make-motion`, `E` = `P/skills/make-explainer`. Inventory taken at commit `5d33e80d` (read with `git grep` and `git ls-files`; nothing was run). Another agent was editing `M/engine` and `M/test/v2` at the time, so Task 1 repeats the import search before it trusts the tables below.

## Global Constraints

- No new npm dependency, in any manifest. Lockfiles change only by losing packages; a version that moves is a stop.
- Every install command written or rewritten by this plan, in a document, a test or code, is `npm ci --ignore-scripts` (with `--prefix <folder>` where a folder is named). Lockfiles are regenerated with `npm install --package-lock-only --ignore-scripts`, which needs the network: the implementer runs it, never a reviewer.
- `M/SKILL.md` keeps `description:` on one line, 41 to 1024 characters, no folded or literal scalar (`>`, `|`). The registry parser truncates a folded value to `>-`.
- No document says anything about audio quality or word-timing accuracy beyond this, quoted from the Voice section of `docs/superpowers/plans/2026-11-15-pa2-gate-report.md`: "on the held-out fixture lines, for the word starts that follow a silence, the predicted start was a median 9 ms from the onset ffmpeg's silence detector found." The same record says "Nobody has listened to any of this audio yet." A document either uses the first sentence verbatim, with its conditions, or says nothing. Not allowed: per-word sync for all words, "independent", word ends, the own-recording path, anything implying a person listened, any adjective about how the voice sounds.
- No version 1 claim is carried into a version 2 document without a command that re-measures it. A figure that cannot be re-measured in this plan is deleted, not reworded.
- Files are removed with `git rm` (with `-r` for a folder that is wholly version 1). Never `rm -rf` on a path another skill, the plugin or the other agent shares. `M/shared/` is a generated copy written by `P/bin/sync-shared.mjs`: nothing inside it is removed or edited by hand.
- After every task: the whole version 2 suite, make-motion's remaining tests, and the repo's suites named in that task's verification are green. A task that cannot get there stops and reports; it does not delete a test to pass.
- One browser-heavy run at a time on this machine (`pgrep -fl chrome-headless-shell` first). Browser suites of make-motion and make-explainer are never run in parallel, by this agent or another.
- Shell rules of this worktree: one plain command per call, literal absolute paths, no `cd`, no variables, loops or heredocs. Use `npm --prefix <absolute folder>` and `node --test "<absolute glob>"`.
- Implementers do not commit. The controller commits one task per commit, pushes the branch, never force-pushes, never merges.
- Repo rules that bind: files under 800 lines, functions under 50, tests first, a guard shown failing before it is trusted, site commands in per-line copy buttons with no comment in `data-copy`, counts changed only through `python3 scripts/sweep_counts.py`.

## Review Focus

1. **A deleted file still referenced.** After Task 3, a search of the whole repository for each deleted script name (`render.mjs`, `validate.mjs`, `check.mjs`, `preview.mjs`, `voice.mjs`, `storyboard.mjs`, `blocks.mjs`, `beats.mjs`, `sketch-icons.mjs`), for `template/`, and for `scripts/lib/spec.mjs` finds only history: `docs/superpowers/`, `P/CHANGELOG.md` entries of released versions, `P/eval/results/`, the generated gallery under `docs/features/showcase/`. Any other hit is a finding. Dynamic loads count: make-explainer loads make-motion by path string (`loadSibling('make-motion', '...')`), which no import search sees.
2. **Security of what stays and what goes.** (a) Each version 1 guarantee has a version 2 test before its version 1 test is deleted: the page's CSP, the request abort for anything off the loopback origin, the server bound to loopback and refusing paths outside its roots, no remote URL in a spec, ffmpeg opened with the file-only protocol whitelist. Task 1 writes the table. (b) `P/bin/test/dependency-pins.test.mjs` is edited to follow the tree; no threshold is loosened and no rule is dropped. The list of reviewed `ensurePinnedFile` callers shrinks, it never grows. (c) After Task 4, `npm audit --package-lock-only` reports 0 for `M` and for each `M/optional/*`, and no package remains in a lockfile that nothing imports.
3. **A skill description that no longer routes, or promises what is gone.** The new description keeps the words a user types (video, animated, explainer, MP4, Reels, TikTok, Shorts, voiceover) and names nothing version 2 lacks (hand-drawn, whiteboard, preview, scrubber, maps, code, Lottie, themes).
4. **One `UsageError`.** Today `M/scripts/lib/spec.mjs` and `M/shared/cli.mjs` each define a class of that name; `M/scripts/make.mjs` maps only the second to exit 2. Unifying them changes which errors print as usage errors. The exit code of every path through `make.mjs` is pinned by a test before and after.
5. **A kept module that lost its only test.** `ffmpeg.mjs`, `browser.mjs`, `optional.mjs`, `pinned-file.mjs`, `beats.mjs`, `doctor-hint.mjs`, `requirements.mjs`, `cutout.mjs`, and the moved `formats.mjs` and cue synthesis each have a test file after Task 3.
6. **make-explainer end to end.** A `motion` section with a version 2 `spec` validates, renders and gets a poster; a version 1 spec gives the validator's own refusal with the section's path in front.
