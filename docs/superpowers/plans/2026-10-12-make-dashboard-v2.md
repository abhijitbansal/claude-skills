# make-dashboard v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give make-dashboard chart kinds with built-in interactivity and alternate views, PNG/SVG/CSV export, shared themes with embedded fonts and a light/dark toggle, and live reload, while the model still writes only one JSON spec.

**Architecture:** A plugin-level `shared/` folder (themes, fonts, contrast checks, error helpers) is synced as a committed copy into each skill so every install path, including `npx skills add`, carries it. New build-time modules expand `kind` charts into Vega-Lite views (with namespaced interaction params) from query results and their DuckDB column types; the page runtime only renders the views it is given. `serve.mjs --watch` rebuilds in-process and pushes server-sent events to a client that is injected only into the served copy, so `dist/index.html` keeps its `default-src 'none'` CSP.

**Tech Stack:** Node ≥ 20 ESM, `node --test`, DuckDB (`@duckdb/node-api`), Vega 6.4 / Vega-Lite 6.5 / vega-embed 7.3 (vendored at build), ajv 8, Playwright 1.64 (dev only), `@fontsource/*` 5.3.0 woff2 files (OFL-1.1).

**Spec:** `docs/superpowers/specs/2026-10-12-make-dashboard-v2-design.md`

## Review Focus

1. **A query that returns zero rows.** The card should say "No rows returned", still offer the Table view, and nothing else should break (no availability crash, no division by zero in `share`). Pinned in Task 5 (expansion) and Task 6 (availability).
2. **NULLs in role columns.** Availability checks ignore NULLs, `share` sums non-NULL values, CSV writes an empty cell, table sort puts NULLs last. Pinned in Task 6 and Task 7.
3. **Column names with spaces, dots or brackets** (`"Total Revenue"`, `"a.b"`, `"x[0]"`). Vega-Lite treats `.` and `[` in `field` as nested access, so expansion must escape them while axis titles show the raw name. Pinned in Task 5 (unit + browser).
4. **A data file that is half-written or briefly invalid while `--watch` runs.** The page shows the error banner and keeps the last good page; the next good save rebuilds. Pinned in Task 8.
5. **Browser storage blocked** (private mode: `localStorage` / `sessionStorage` throw). The page renders, the theme toggle still works for the visit, and view state just isn't remembered. Pinned in Task 3 (theme) and Task 6 (views).

- [ ] **Step 3: Write `bin/sync-shared.mjs`**

```js
#!/usr/bin/env node
// Copy plugins/portable-artifacts/shared/ into every skill as skills/<skill>/shared/.
// Every install path (Claude plugin, bin/install.mjs, `npx skills add`) copies
// whole skill folders, so each skill must carry its own copy.
//   node bin/sync-shared.mjs                 write the copies
//   node bin/sync-shared.mjs --check         exit 1 and list drift, write nothing
//   --plugin <dir>                           operate on another plugin folder (tests)
import fs from 'node:fs';
import path from 'node:path';
import { parseArgs } from 'node:util';
import { fileURLToPath } from 'node:url';

const PLUGIN = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..');
const EXCLUDE_TOP = new Set(['test', 'README.md']);
export const GENERATED_NOTE = '# Generated copy\n\nDo not edit. The source is `plugins/portable-artifacts/shared/`.\nAfter editing it, run `node bin/sync-shared.mjs` from `plugins/portable-artifacts`.\n';

function walk(root, rel = '') {
  const out = [];
  for (const entry of fs.readdirSync(path.join(root, rel), { withFileTypes: true })) {
    const r = rel ? `${rel}/${entry.name}` : entry.name;
    if (!rel && EXCLUDE_TOP.has(entry.name)) continue;
    if (entry.isDirectory()) out.push(...walk(root, r));
    else if (entry.isFile()) out.push(r);
  }
  return out;
}

// rel path -> Buffer, exactly what every copy must contain.
function expected(pluginDir) {
  const shared = path.join(pluginDir, 'shared');
  const files = new Map(walk(shared).map((r) => [r, fs.readFileSync(path.join(shared, r))]));
  files.set('GENERATED.md', Buffer.from(GENERATED_NOTE));
  return files;
}

function skills(pluginDir) {
  const root = path.join(pluginDir, 'skills');
  return fs.readdirSync(root)
    .filter((d) => fs.existsSync(path.join(root, d, 'SKILL.md')))
    .sort();
}

export function diffShared(pluginDir) {
  const want = expected(pluginDir);
  const problems = [];
  for (const skill of skills(pluginDir)) {
    const copy = path.join(pluginDir, 'skills', skill, 'shared');
    const have = fs.existsSync(copy) ? new Set(walk(copy)) : new Set();
    const files = [...new Set([...want.keys(), ...have])].sort();
    for (const file of files) {
      if (!want.has(file)) problems.push({ skill, file, problem: 'extra' });
      else if (!have.has(file)) problems.push({ skill, file, problem: 'missing' });
      else if (!fs.readFileSync(path.join(copy, file)).equals(want.get(file))) problems.push({ skill, file, problem: 'changed' });
    }
  }
  return problems;
}

export function syncShared(pluginDir) {
  const want = expected(pluginDir);
  for (const skill of skills(pluginDir)) {
    const copy = path.join(pluginDir, 'skills', skill, 'shared');
    fs.rmSync(copy, { recursive: true, force: true });
    for (const [file, body] of want) {
      fs.mkdirSync(path.dirname(path.join(copy, file)), { recursive: true });
      fs.writeFileSync(path.join(copy, file), body);
    }
  }
}

function main() {
  let values;
  try {
    ({ values } = parseArgs({ args: process.argv.slice(2), options: { check: { type: 'boolean' }, plugin: { type: 'string' } }, strict: true }));
  } catch (e) {
    process.stderr.write(`sync-shared: ${e.message.split('. ')[0]}; accepted: --check, --plugin <dir>\n`);
    process.exit(2);
  }
  const dir = path.resolve(values.plugin ?? PLUGIN);
  if (values.check) {
    const problems = diffShared(dir);
    for (const p of problems) process.stderr.write(`skills/${p.skill}/shared/${p.file}: ${p.problem}\n`);
    if (problems.length) {
      process.stderr.write('shared/ copies are out of date; run: node bin/sync-shared.mjs (from plugins/portable-artifacts)\n');
      process.exit(1);
    }
    process.stdout.write('shared/ copies are in sync\n');
    return;
  }
  syncShared(dir);
  process.stdout.write(`synced shared/ into ${skills(dir).join(', ')}\n`);
}

if (process.argv[1] && fs.realpathSync(process.argv[1]) === fileURLToPath(import.meta.url)) main();
```

```js
// WCAG 2.x contrast maths and the theme rules every shipped theme must pass.
// Categorical colours are NOT gated here: the dataviz relief rule applies
// (legend + Table view on every card); they are validated per theme surface
// with the dataviz palette validator when a theme changes.

const channel = (c) => {
  const s = c / 255;
  return s <= 0.04045 ? s / 12.92 : ((s + 0.055) / 1.055) ** 2.4;
};

export function relativeLuminance(hex) {
  const n = Number.parseInt(hex.slice(1), 16);
  return 0.2126 * channel(n >> 16) + 0.7152 * channel((n >> 8) & 255) + 0.0722 * channel(n & 255);
}

export function contrastRatio(a, b) {
  const [hi, lo] = [relativeLuminance(a), relativeLuminance(b)].sort((x, y) => y - x);
  return (hi + 0.05) / (lo + 0.05);
}

const TEXT = ['text', 'text2', 'text3'];
const UI = ['accent', 'warn', 'good', 'bad'];
const SEQ = ['seq1', 'seq2', 'seq3', 'seq4', 'seq5', 'seq6', 'seq7'];
const fmt = (r) => `${r.toFixed(2)}:1`;

export function checkTheme(theme) {
  const errors = [];
  for (const mode of ['light', 'dark']) {
    const t = theme[mode];
    for (const k of TEXT) {
      for (const bg of ['page', 'surface']) {
        const r = contrastRatio(t[k], t[bg]);
        if (r < 4.5) errors.push({ path: `${mode}.${k}`, message: `${t[k]} is ${fmt(r)} against ${bg}; needs 4.5:1` });
      }
    }
    for (const k of UI) {
      const r = contrastRatio(t[k], t.surface);
      if (r < 3) errors.push({ path: `${mode}.${k}`, message: `${t[k]} is ${fmt(r)} against surface; needs 3:1` });
    }
    const ramp = SEQ.map((k) => contrastRatio(t[k], t.surface));
    if (ramp.some((r, i) => i > 0 && r <= ramp[i - 1])) {
      errors.push({ path: `${mode}.seq`, message: `seq1..seq7 must get stronger against surface at every step (got ${ramp.map(fmt).join(', ')})` });
    }
    if (ramp[6] < 3) errors.push({ path: `${mode}.seq7`, message: `${t.seq7} is ${fmt(ramp[6])} against surface; needs 3:1` });
  }
  return errors;
}
```

```js
// Theme JSON -> CSS custom properties (light, dark, data-theme overrides) and
// @font-face rules with embedded woff2. Zero dependencies: skills with
// different lockfiles import this file from their own shared/ copy.
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const HERE = path.dirname(fileURLToPath(import.meta.url));
const THEMES = path.join(HERE, 'themes');
const FONTS = path.join(HERE, 'fonts');
const NAME = /^[a-z][a-z0-9-]*$/;

export const DEFAULT_THEME = 'paper';

// JSON token -> CSS variable. The CSS names are the ones template/page.html
// and template/runtime.js read; keep them stable.
const VARS = {
  page: '--page', surface: '--surface', text: '--text', text2: '--text-2', text3: '--text-3',
  line: '--line', grid: '--grid', accent: '--accent', accentSoft: '--accent-soft',
  warn: '--warn', good: '--good', bad: '--bad',
  cat1: '--s1', cat2: '--s2', cat3: '--s3', cat4: '--s4', cat5: '--s5', cat6: '--s6', cat7: '--s7', cat8: '--s8',
  seq1: '--seq1', seq2: '--seq2', seq3: '--seq3', seq4: '--seq4', seq5: '--seq5', seq6: '--seq6', seq7: '--seq7',
};
export const TOKENS = Object.keys(VARS);

export class ThemeError extends Error {
  constructor(name, available) {
    super(`unknown theme ${JSON.stringify(name)}; available: ${available.join(', ')}`);
    this.name = 'ThemeError';
    this.available = available;
  }
}

export function listThemes() {
  return fs.readdirSync(THEMES).filter((f) => f.endsWith('.json')).map((f) => f.slice(0, -5)).sort();
}

export function loadTheme(name) {
  const available = listThemes();
  if (!NAME.test(String(name)) || !available.includes(name)) throw new ThemeError(name, available);
  return JSON.parse(fs.readFileSync(path.join(THEMES, `${name}.json`), 'utf8'));
}

const family = (f) => `"${f.family}", ${f.fallback}`;

function vars(tokens, fonts) {
  const colours = TOKENS.map((k) => `${VARS[k]}:${tokens[k]}`).join(';');
  return fonts
    ? `${colours};--font-display:${family(fonts.display)};--font:${family(fonts.body)};--mono:${family(fonts.mono)}`
    : colours;
}

// One @font-face per distinct family+weight across the three roles.
function faces(theme) {
  const seen = new Map();
  for (const role of Object.values(theme.fonts)) {
    for (const [weight, file] of Object.entries(role.weights)) seen.set(`${role.family}|${weight}`, { family: role.family, weight, file });
  }
  return [...seen.values()];
}

export function fontPayloadBytes(theme) {
  return [...new Set(faces(theme).map((f) => f.file))].reduce((n, file) => n + fs.statSync(path.join(FONTS, file)).size, 0);
}

export function themeCss(theme) {
  const fontFaces = faces(theme).map(({ family: fam, weight, file }) => {
    const b64 = fs.readFileSync(path.join(FONTS, file)).toString('base64');
    return `@font-face{font-family:"${fam}";font-style:normal;font-weight:${weight};font-display:swap;src:url(data:font/woff2;base64,${b64}) format("woff2")}`;
  });
  return [
    ...fontFaces,
    `:root{color-scheme:light;${vars(theme.light, theme.fonts)}}`,
    `@media (prefers-color-scheme: dark){:root:not([data-theme="light"]){color-scheme:dark;${vars(theme.dark)}}}`,
    `:root[data-theme="dark"]{color-scheme:dark;${vars(theme.dark)}}`,
  ].join('\n');
}
```

```js
import assert from 'node:assert/strict';
import fs from 'node:fs';
import os from 'node:os';
import path from 'node:path';
import { spawnSync } from 'node:child_process';
import { fileURLToPath } from 'node:url';

const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '../..');
const BUILD = path.join(ROOT, 'scripts/build.mjs');

export async function launchBrowser() {
  const { chromium } = await import('playwright');
  try {
    return await chromium.launch();
  } catch (first) {
    if (!/Executable doesn't exist/i.test(first.message)) throw first;
    return chromium.launch({ channel: 'chrome' });
  }
}

let cached;
export async function haveBrowser() {
  if (cached === undefined) {
    try { await (await launchBrowser()).close(); cached = true; } catch { cached = false; }
  }
  return cached;
}

export function buildProject(spec, { theme } = {}) {
  const dir = fs.mkdtempSync(path.join(os.tmpdir(), 'dash-ui-'));

  const args = [BUILD, file, '--out', out, ...(theme ? ['--theme', theme] : [])];
  const r = spawnSync(process.execPath, args, { encoding: 'utf8' });
  assert.equal(r.status, 0, r.stdout + r.stderr);
  return { dir, file, out, html: fs.readFileSync(path.join(out, 'index.html'), 'utf8') };
```

```js
// Pure helpers for the dashboard page. Loaded as a classic script in the page
// and through node:vm in tests, so: no imports, no DOM access here.
(function (root) {
  'use strict';
  var THEMES = ['auto', 'light', 'dark'];

  function nextTheme(mode) {
    var i = THEMES.indexOf(mode);
    return THEMES[(i + 1) % THEMES.length];
  }

  // Storage can be missing or throw (private mode, blocked site data).
  function readStore(storage, key) {
    try { return storage ? storage.getItem(key) : null; } catch (e) { return null; }
  }

  function writeStore(storage, key, value) {
    try { if (storage) storage.setItem(key, value); } catch (e) { /* not remembered; fine */ }
  }

  root.PA = { nextTheme: nextTheme, readStore: readStore, writeStore: writeStore };
})(typeof window !== 'undefined' ? window : globalThis);
```

```js
  donut: { label: 'Donut', required: ['x', 'y'], optional: [], types: { x: N, y: Q }, views: ['bar'] },

export function classOf(duckType) {
  const t = String(duckType);
  if (t === 'DATE' || t.startsWith('TIMESTAMP')) return 'temporal';
  if (/^(U?(TINY|SMALL|BIG|HUGE)?INT(EGER)?|UBIGINT|FLOAT|DOUBLE|REAL|DECIMAL\(\d+,\d+\))$/.test(t)) return 'quantitative';
  return 'nominal';
}

// Vega-Lite reads "." and "[" in a field string as nested access; escape them.
export function fieldRef(column) {
  return String(column).replace(/[\\.[\]]/g, '\\$&');
}

const NEED = { quantitative: 'a numeric column', temporal: 'a date or timestamp column', nominal: 'a text column' };
const IS = { quantitative: 'numeric', temporal: 'a date', nominal: 'text' };

function need(classes) {
  return classes.map((c) => NEED[c]).join(' or ');
}

function checkChart(chart, p, described) {
  const kind = KINDS[chart.kind];
  if (!kind) return []; // unknown kind is a schema (enum) error already
  const errors = [];
  const roles = [...kind.required, ...kind.optional];
  const rolesNote = `(roles: ${roles.join(', ')})`;
  for (const role of ROLES) {
    if (chart[role] !== undefined && !roles.includes(role)) errors.push({ path: pathJoin(p, role), message: `kind ${JSON.stringify(chart.kind)} does not use ${role} ${rolesNote}` });
  }
  for (const role of kind.required) {
    if (chart[role] === undefined) errors.push({ path: pathJoin(p, role), message: `required for kind ${JSON.stringify(chart.kind)} ${rolesNote}` });
  }
  const q = described[chart.query];
  if (q) {
    for (const role of roles) {
      const column = chart[role];
      if (column === undefined) continue;
      const i = q.columns.indexOf(column);
      if (i < 0) {
        const hint = didYouMean(column, q.columns);
        errors.push({ path: pathJoin(p, role), message: `${JSON.stringify(column)} is not a column of query ${JSON.stringify(chart.query)} (columns: ${q.columns.join(', ')})${hint ? `; did you mean ${JSON.stringify(hint)}?` : ''}` });
        continue;
      }
      const cls = classOf(q.types[i]);
      if (!kind.types[role].includes(cls)) {
        errors.push({ path: pathJoin(p, role), message: `${JSON.stringify(column)} is ${IS[cls]} (${q.types[i]}); ${role} of kind ${JSON.stringify(chart.kind)} needs ${need(kind.types[role])}` });
      }
    }
  }
  const offered = [...kind.views, 'table'];
  (chart.views ?? []).forEach((v, i) => {
    if (offered.includes(v)) return;
    const hint = didYouMean(v, offered);
    errors.push({ path: pathJoin(pathJoin(p, 'views'), i), message: `kind ${JSON.stringify(chart.kind)} has no view ${JSON.stringify(v)}; ${hint ? `did you mean ${JSON.stringify(hint)}? ` : ''}(views: ${offered.join(', ')})` });
  });
  return errors;
}

export function roleErrors(spec, described) {
  return (spec.charts ?? []).flatMap((chart, i) => (chart.kind ? checkChart(chart, pathJoin('charts', i), described) : []));
}
```

```js
// so they never collide with params a model wrote. Verified to evaluate under
// vega-embed { ast: true } and the page's strict CSP (spike, 2026-10-12).

export const HOVER = { name: 'pa_hover', select: { type: 'point', on: 'pointerover', clear: 'pointerout' } };
export const ZOOM_X = { name: 'pa_zoom', select: { type: 'interval', encodings: ['x'] }, bind: 'scales' };
export const ZOOM_XY = { name: 'pa_zoom', select: { type: 'interval' }, bind: 'scales' };
export const NEAREST_X = { name: 'pa_x', select: { type: 'point', encodings: ['x'], nearest: true, on: 'pointerover', clear: 'pointerout' } };
export const legendParam = (field) => ({ name: 'pa_legend', select: { type: 'point', fields: [field] }, bind: 'legend' });
const dimUnless = (param) => ({ condition: { param, empty: true, value: 1 }, value: param === 'pa_legend' ? 0.2 : 0.55 });

export function addTooltips(node) {
  if (Array.isArray(node)) return node.map(addTooltips);
  if (!node || typeof node !== 'object') return node;
  const out = {};
  for (const [k, v] of Object.entries(node)) out[k] = addTooltips(v);
  if (typeof node.mark === 'string') out.mark = { type: node.mark, tooltip: true };
  else if (node.mark && typeof node.mark === 'object' && node.mark.tooltip === undefined) out.mark = { ...node.mark, tooltip: true };
  return out;
}

// For a kind: which params to add and which opacity encoding expresses them.
// `colorField` is the escaped field ref of the colour role, or undefined.
export function interactionsFor(kind, { colorField } = {}) {
  switch (kind) {
    case 'bar':
    case 'histogram':
    case 'heatmap':
      return { params: [HOVER], opacity: dimUnless('pa_hover') };
    case 'stacked-bar':
    case 'grouped-bar':
    case 'donut':
      return { params: [legendParam(colorField)], opacity: dimUnless('pa_legend') };
    case 'scatter':
    case 'bubble':
      return colorField
        ? { params: [ZOOM_XY, legendParam(colorField)], opacity: dimUnless('pa_legend') }
        : { params: [ZOOM_XY] };
    default:
      return { params: [] }; // line/area: built as layers in views.mjs; boxplot: tooltip only
  }
}

const hasParams = (node) => {
  if (Array.isArray(node)) return node.some(hasParams);
  if (!node || typeof node !== 'object') return false;
  return Array.isArray(node.params) || Object.values(node).some(hasParams);
};
const isUnit = (vl) => !['layer', 'hconcat', 'vconcat', 'concat', 'repeat', 'facet', 'spec'].some((k) => k in vl);
const markOf = (vl) => (typeof vl.mark === 'string' ? vl.mark : vl.mark?.type);

// Best effort for model-written Vega-Lite: tooltips everywhere; a legend
// filter or zoom only on simple unit specs that declare no params of their own.
export function enhanceRaw(vl, classes) {
  const out = addTooltips(vl);
  if (hasParams(vl) || !isUnit(vl)) return out;
```

```js
// Expand kind charts into Vega-Lite views at build time, from the query rows
// and their DuckDB column types. The page renders exactly what this returns.
import { KINDS, classOf, fieldRef } from './kinds.mjs';
import { addTooltips, enhanceRaw, interactionsFor, NEAREST_X, ZOOM_X, legendParam } from './interact.mjs';

const AXIS_FORMAT = { number: ',.2~f', currency: '$,.2~f', percent: '.1~%', compact: '.3~s' };
const HORIZONTAL_LABEL = 12;
const HORIZONTAL_COUNT = 8;
const TABLE = { name: 'table', label: 'Table' };

export function temporalUnit(values) {
  const dates = values.filter((v) => v !== null && v !== undefined).map((v) => new Date(String(v).length === 10 ? `${v}T00:00:00Z` : v));
  if (!dates.length || dates.some((d) => Number.isNaN(d.getTime()))) return null;
  const midnight = dates.every((d) => d.getUTCHours() === 0 && d.getUTCMinutes() === 0 && d.getUTCSeconds() === 0 && d.getUTCMilliseconds() === 0);
  if (!midnight) return null;
  if (dates.every((d) => d.getUTCDate() === 1 && d.getUTCMonth() === 0)) return 'utcyear';
  if (dates.every((d) => d.getUTCDate() === 1)) return 'utcyearmonth';
  return 'utcyearmonthdate';
}

// Per-chart context the builders share: field defs for every role in use.
function context(chart, result) {
  const cls = (col) => classOf(result.types[result.columns.indexOf(col)]);
  const def = (role, extra = {}) => {
    const col = chart[role];
    if (col === undefined) return undefined;
    const type = cls(col);
    const base = { field: fieldRef(col), type, title: col };
    if (type === 'temporal') {
      const unit = temporalUnit(result.rows.map((r) => r[col]));
      Object.assign(base, unit ? { timeUnit: unit } : {}, { scale: { type: 'utc' } });
    }
    if (type === 'quantitative' && chart.format) base.axis = { format: AXIS_FORMAT[chart.format] };
    return { ...base, ...extra };
  };
  const labels = chart.x !== undefined ? result.rows.map((r) => String(r[chart.x] ?? '')) : [];
  const distinct = new Set(labels);
  const horizontal = chart.x !== undefined && cls(chart.x) === 'nominal'
    && (distinct.size > HORIZONTAL_COUNT || labels.some((l) => l.length > HORIZONTAL_LABEL));
  // The legend field: donut colours by x; every other kind by its color role.
  const legend = chart.kind === 'donut' ? chart.x : chart.color;
  return { def, horizontal, colorField: legend === undefined ? undefined : fieldRef(legend) };
}

// Bars on a time axis read better as ordinal bands.
const banded = (d) => {
  if (!d || d.type !== 'temporal') return d;
  const { scale, ...rest } = d; // a utc scale does not apply to ordinal bands
  return { ...rest, type: 'ordinal' };
};

function bar(ctx, { color, stack, offset, sort } = {}) {
  const x = banded(ctx.def('x', { sort: sort ?? null }));
  const y = ctx.def('y', stack ? { stack } : {});
  const enc = ctx.horizontal ? { y: x, x: y } : { x, y };
  if (color) enc.color = ctx.def('color');
  if (offset) enc[ctx.horizontal ? 'yOffset' : 'xOffset'] = { field: ctx.colorField };
  return { mark: 'bar', encoding: enc, ...(ctx.horizontal ? { height: { step: 24 } } : {}) };
}

function lineLike(ctx, mark) {
  const x = ctx.def('x');
  const y = ctx.def('y');
  const color = ctx.def('color');
  const main = { params: [ZOOM_X, ...(color ? [legendParam(ctx.colorField)] : [])], mark, encoding: { y, ...(color ? { color, opacity: { condition: { param: 'pa_legend', empty: true, value: 1 }, value: 0.2 } } : {}) } };
  const rule = { params: [NEAREST_X], mark: { type: 'rule', tooltip: false }, encoding: { opacity: { condition: { param: 'pa_x', empty: false, value: 0.5 }, value: 0 } } };
  const dots = { mark: { type: 'point', filled: true }, encoding: { y, ...(color ? { color } : {}), opacity: { condition: { param: 'pa_x', empty: false, value: 1 }, value: 0 } } };
  return { encoding: { x }, layer: [main, rule, dots] };
}

const BUILDERS = {
  bar: (ctx) => bar(ctx),
  'stacked-bar': (ctx) => bar(ctx, { color: true }),
  'grouped-bar': (ctx) => bar(ctx, { color: true, offset: true }),
  line: (ctx) => lineLike(ctx, 'line'),
  area: (ctx) => lineLike(ctx, 'area'),
  scatter: (ctx) => ({ mark: 'point', encoding: { x: ctx.def('x'), y: ctx.def('y'), ...(ctx.colorField ? { color: ctx.def('color') } : {}) } }),
  bubble: (ctx) => ({ mark: 'circle', encoding: { x: ctx.def('x'), y: ctx.def('y'), size: ctx.def('size'), ...(ctx.colorField ? { color: ctx.def('color') } : {}) } }),
  heatmap: (ctx) => ({ mark: 'rect', encoding: { x: banded(ctx.def('x')), y: banded(ctx.def('y')), color: ctx.def('value') } }),
  histogram: (ctx) => ({ mark: 'bar', encoding: { x: ctx.def('value', { bin: { maxbins: 20 } }), y: { aggregate: 'count', type: 'quantitative', title: 'Count' } } }),
  boxplot: (ctx) => ({ mark: { type: 'boxplot', extent: 1.5 }, encoding: { y: ctx.def('value'), ...(ctx.def('x') ? { x: ctx.def('x') } : {}) } }),
  donut: (ctx) => ({ mark: { type: 'arc', innerRadius: 60 }, encoding: { theta: ctx.def('y', { stack: true }), color: ctx.def('x') } }),
};

// Adds the kind's params and opacity to a built unit view.
function interactive(kind, vl, ctx) {
  const { params, opacity } = interactionsFor(kind, ctx);
  const withParams = params.length ? { params, ...vl } : vl;
  const withOpacity = opacity && !vl.layer ? { ...withParams, encoding: { ...withParams.encoding, opacity } } : withParams;
  return addTooltips(withOpacity);
}

export function buildView(name, chart, ctx) {
  return interactive(name, BUILDERS[name](ctx), ctx);
}

function expandKind(chart, result) {
  const ctx = context(chart, result);
  const primary = { name: chart.kind, label: KINDS[chart.kind].label, vegaLite: buildView(chart.kind, chart, ctx) };
  return { views: [primary, TABLE], errors: [] };
}

function expandRaw(chart, result) {
  const classes = Object.fromEntries(result.columns.map((c, i) => [c, classOf(result.types[i])]));
  return { views: [{ name: 'chart', label: 'Chart', vegaLite: enhanceRaw(chart.vegaLite, classes) }, TABLE], errors: [] };
}

export function expandCharts(spec, results) {
  const charts = [];
  const errors = [];
  for (const chart of spec.charts ?? []) {
    const result = results[chart.query];
    const out = chart.kind ? expandKind(chart, result) : expandRaw(chart, result);
    errors.push(...out.errors);
    charts.push({
      id: chart.id, title: chart.title, query: chart.query, width: chart.width ?? 'full',
      pair: false, empty: result.rowCount === 0, views: out.views,
    });
  }
  return { charts, errors };
}
```

```js
  var FORMULA = /^[=+\-@\t\r]/;

  function csvCell(v) {
    if (v === null || v === undefined) return '';
    var s = typeof v === 'object' ? JSON.stringify(v) : String(v);
    // Text a spreadsheet would run as a formula gets a leading quote.
    if (typeof v === 'string' && FORMULA.test(s)) s = "'" + s;
    return /[",\r\n]/.test(s) ? '"' + s.replace(/"/g, '""') + '"' : s;
  }

  function toCsv(columns, rows) {
    var lines = [columns.map(csvCell).join(',')];
    rows.forEach(function (r) { lines.push(columns.map(function (c) { return csvCell(r[c]); }).join(',')); });
    return lines.join('\r\n') + '\r\n';
  }

  function fileStem(title) {
    var s = String(title).toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/^-+|-+$/g, '').slice(0, 60).replace(/-+$/, '');
    return s || 'chart';
  }
```

```js
function serve(args) {
  const child = spawn(process.execPath, [SERVE, ...args], { stdio: ['ignore', 'pipe', 'pipe'] });
  children.push(child);
  return new Promise((resolve, reject) => {
    let out = '';
    child.stdout.on('data', (d) => {
      out += d;
      const m = out.match(/http:\/\/127\.0\.0\.1:(\d+)\//);
      const tok = out.match(/token: (\w+)/);
      if (m && tok) resolve({ child, port: Number(m[1]), token: tok[1] });
    });
    child.on('exit', (code) => reject(new Error(`serve exited ${code}: ${out}`)));
  });
}

function events(port) {
  const seen = [];
  let buf = '';
  const req = http.get({ host: '127.0.0.1', port, path: '/events' }, (res) => {
    res.setEncoding('utf8');
    res.on('data', (chunk) => {
      buf += chunk;
      let i;
      while ((i = buf.indexOf('\n\n')) >= 0) {
        const block = buf.slice(0, i);
        buf = buf.slice(i + 2);
        const m = block.match(/^event: ([\w-]+)\ndata: (.*)$/m);
        if (m) seen.push({ event: m[1], data: JSON.parse(m[2]) });
      }
    });
  });
  return { seen, close: () => req.destroy() };
}

const until = async (fn, ms = 8000) => {
  const end = Date.now() + ms;
  while (Date.now() < end) { if (fn()) return; await sleep(50); }
  throw new Error('timed out');
};

const request = (port, { method = 'GET', path: p = '/', headers = {} } = {}) => new Promise((resolve, reject) => {
  const req = http.request({ host: '127.0.0.1', port, method, path: p, headers }, (res) => {
    let body = '';
    res.on('data', (d) => { body += d; });
    res.on('end', () => resolve({ status: res.statusCode, body }));
  });
  req.on('error', reject);
  req.end();
});
```

```js
import fs from 'node:fs';
import http from 'node:http';

export function createRebuilder(run) {
  let running = null;
  let pending = false;
  const loop = async () => {
    do {
      pending = false;
      await run();
    } while (pending);
    running = null;
  };
  return {
    trigger() {
      if (running) { pending = true; return; }
      running = loop();
    },
    idle: () => running ?? Promise.resolve(),
  };
}

// Watch parent directories (rename-and-replace saves defeat a file watch),
// filter by file name, debounce bursts into one call.
export function watchFiles(paths, onChange, { debounceMs = 300 } = {}) {
  const byDir = new Map();
  for (const p of paths) {
    const dir = path.dirname(p);
    if (!byDir.has(dir)) byDir.set(dir, new Set());
    byDir.get(dir).add(path.basename(p));
  }
  let timer = null;
  const watchers = [...byDir].map(([dir, names]) => {
    const w = fs.watch(dir, (_event, name) => {
      if (name && !names.has(String(name))) return;
      clearTimeout(timer);
      timer = setTimeout(onChange, debounceMs);
    });
    w.on('error', () => {}); // directory removed: stop reloading quietly
    return w;
  });
  return { close: () => { clearTimeout(timer); watchers.forEach((w) => w.close()); } };
}

export async function startLiveServer({ specFile, port = 0, interval, theme, allowOutside = false, timeoutMs, out }) {
  const token = crypto.randomBytes(16).toString('hex');
  const clients = new Set();
  const state = { html: null, watcher: null, watchKey: '' };
  const send = (event, payload) => { for (const c of clients) c.write(`event: ${event}\ndata: ${JSON.stringify(payload)}\n\n`); };

  async function build() {
    let result;
    try {
      result = await buildDashboard(specFile, { out, theme, allowOutside, timeoutMs });
    } catch (e) {
      result = { ok: false, errors: [{ path: '', message: e.message.split('\n')[0] }] };
    }
    if (!result.ok) {
      send('build-error', result.errors);
      return result;
    }
    state.html = liveHtml(fs.readFileSync(result.target, 'utf8'), { token });
    const key = result.watch.join('\n');
    if (key !== state.watchKey) {
      state.watcher?.close();
      state.watcher = watchFiles(result.watch, () => rebuilder.trigger());
      state.watchKey = key;
    }
    send('rebuilt', { at: new Date().toISOString() });
    return result;
  }
  const rebuilder = createRebuilder(build);

  const first = await build();
  if (!first.ok) return { ok: false, errors: first.errors };
  const timer = interval ? setInterval(() => rebuilder.trigger(), interval * 1000) : null;

  const server = http.createServer((req, res) => {
    const { port: bound } = server.address();
    if (req.headers.host !== `127.0.0.1:${bound}` && req.headers.host !== `localhost:${bound}`) return res.writeHead(403).end('forbidden host');
    const pathname = new URL(req.url, 'http://127.0.0.1').pathname;
    if (req.method === 'POST' && pathname === '/rebuild') {
      if (req.headers['x-pa-token'] !== token) return res.writeHead(403).end('forbidden');
      rebuilder.trigger();
      return res.writeHead(202).end('rebuilding');
    }
    if (req.method !== 'GET' && req.method !== 'HEAD') return res.writeHead(405).end('method not allowed');
    if (pathname === '/events') {
      res.writeHead(200, { 'content-type': 'text/event-stream', 'cache-control': 'no-store', connection: 'keep-alive' });
      res.write(': connected\n\n');
      clients.add(res);
      const ping = setInterval(() => res.write(': ping\n\n'), KEEPALIVE_MS);
      req.on('close', () => { clearInterval(ping); clients.delete(res); });
      return undefined;
    }
    if (pathname === '/' || pathname === '/index.html') {
      res.writeHead(200, { 'content-type': 'text/html; charset=utf-8', 'cache-control': 'no-store' });
      return res.end(state.html);
    }
    return res.writeHead(404).end('not found');
  });
  await new Promise((resolve, reject) => { server.once('error', reject); server.listen(port, '127.0.0.1', resolve); });
  return {
    ok: true,
    url: `http://127.0.0.1:${server.address().port}/`,
    token,
    close: () => new Promise((resolve) => {
      clearInterval(timer);
      state.watcher?.close();
      for (const c of clients) c.end();
      server.close(() => resolve());
      server.closeAllConnections();
    }),
  };
}
```
