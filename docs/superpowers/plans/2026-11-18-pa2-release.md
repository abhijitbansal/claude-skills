## Global Constraints

- Offline, OSI licences only, Node 20 or later. No new npm dependency and no version change in any manifest except the two bumps of Task 7.
- **One browser-heavy run at a time on this machine, across all agents.** Before every `make.mjs` build, `shot.mjs`, `check.mjs` or test suite: `pgrep -fl chrome-headless-shell`. If it lists anything, wait. Never start two. No ad-hoc screenshot loop: screenshots come from `node P/shared/shot.mjs <page> --widths 390,1280 --out <dir>`.
- **Command limits (put in every dispatch prompt):** one plain command per Bash call with literal absolute paths; no `cd … &&`, pipes, `;`, shell variables, loops or heredocs; scripts via the Write tool under `W/.scratch/`; noisy commands run bare; no `rm`, no `sleep`, no `timeout`; no `sed -i`. Use `npm --prefix <absolute folder>` and `node --test "<absolute glob>"`.
- **Implementers do not commit, stage or push.** The controller commits one task per commit with the single trailer `Co-Authored-By: Claude <noreply@anthropic.com>`, pushes the branch, never force-pushes, never merges.
- **Honest copy.** Every figure and feature claim in a film, a page or a document is in a claims table with its source, re-read or re-run at execution. Nothing says the audio sounds right, clear or in sync: nobody has listened. "Offline" is always qualified by the one voice model download. The eval is "one run of ten prompts on Claude Code, 2026-11-18", never a rate.
- **No engine change inside a film task.** A revision round changes the film's script only. A defect in the engine stops the task and goes to the lead, who dispatches a separate fix with a failing test first. A look's standing rulings in `W/docs/superpowers/plans/2026-11-15-pa2-gate-report.md` are not reopened.
- **Dates.** `SOURCE_DATE_EPOCH=1794960000` (18 November 2026, 00:00 UTC) for every render and page build, in the form `env SOURCE_DATE_EPOCH=1794960000 node …`. If the release heading carries another date, recompute (86,400 per day), use one value everywhere and record it in the pull request body.
- Goldens and baselines are not regenerated. Counts change only through `python3 W/scripts/sweep_counts.py`.
- Site commands keep the per-line copy contract of `W/CLAUDE.md`: `.code.cmds` > `.cl` > `code.ct` + `button.copy`, no `#` comment in `data-copy`.
- Files under 800 lines, functions under 50, tests first.

## Review Focus

1. **A claim with no source.** Each sentence a film speaks or shows, and each figure in README, USAGE and the feature page, maps to a row of a claims table. A row whose source no longer says it is a finding.
2. **The silent path.** If the films ship without a voice, no page, alt text, meta line or note says "voiceover", and the page test asserts that.
3. **A dead link or missing file.** Every `src`, `poster`, `href` and README image under the changed sections resolves to a tracked file; the old anchors `#gallery` and `#gallery-motion-1-4` still resolve.
4. **The gate was real.** Each look reviewer saw only contact sheets and the rubric: no script, no notes, no change list. Verdicts are quoted.
5. **A stale version 1 sentence.** After Task 6 no sentence outside the labelled archive, released CHANGELOG entries and `P/eval/results/` describes a version 1 clip as current or says "the clips on this page were made with make-motion 1.x" about a version 2 clip.
